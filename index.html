CSS — одяг для вебсторінки

Інформатика, 8 клас. HTML говорить, що є на сторінці (заголовок, абзац, картинка), а CSS — як це виглядає: кольори, шрифти, відступи, розташування.

Що таке CSS

CSS (Cascading Style Sheets — «каскадні таблиці стилів») — мова опису зовнішнього вигляду HTML-документа. Один файл стилів можна підключити до багатьох сторінок, і весь сайт отримає єдиний вигляд. Щоб змінити колір заголовків на всьому сайті, достатньо виправити одне правило.

Три способи підключити стилі

1. Вбудований (атрибут style)

<p style="color: red;">Червоний текст</p>

2. Внутрішній (тег style у head)

<head>
  <style>
    p { color: blue; }
  </style>
</head>

3. Зовнішній (окремий файл .css) — найкращий

<head>
  <link rel="stylesheet" href="style.css">
</head>

Зовнішній файл зручний: стилі окремо від розмітки, один файл — для всього сайту.

Синтаксис правила

h1 {                 /* селектор: до чого застосувати */
  color: darkblue;      /* властивість: значення; */
  font-size: 32px;
}

Правило складається із селектора та блоку оголошень у фігурних дужках. Кожне оголошення — це пара «властивість: значення» і закінчується крапкою з комою.

Кольори задають назвою (red), шістнадцятковим кодом (#ff0000) або через rgb(255, 0, 0).

Блокова модель

Кожен елемент — це прямокутна коробка з чотирьох шарів, від центру назовні:

content → padding → border → margin

content — сам вміст; padding — внутрішній відступ між вмістом і рамкою; border — рамка; margin — зовнішній відступ від сусідніх елементів.

.card {
  padding: 16px;
  border: 2px solid navy;
  margin: 20px;
}

Практика: змінюй стилі наживо

Рухай повзунки й обирай кольори — код унизу оновлюється сам. Скопіюй його у свій файл style.css.
